# Domain model

Package: `RootBlocks` · Target: `netstandard2.1` · Dependencies: `MediatR.Contracts`

These are the core DDD building blocks. They have no infrastructure dependencies. The only external reference is `MediatR.Contracts`, which provides `INotification` so that domain events can be dispatched without the domain project referencing MediatR itself.

| Type | Namespace |
|------|-----------|
| `Entity<T>`, `ValueObject`, `Enumeration`, `TranslatableEnumeration`, `DomainEvent` | `RootBlocks.Aggregate` |
| `IAggregateRoot`, `IEntity`, `IDatable` | `RootBlocks.Aggregate.Abstractions` |
| `IRepository<T>`, `IUnitOfWork` | `RootBlocks.Persistence.Abstractions` |
| `DomainException`, `EntityNotFoundException<T>`, `EntityAlreadyExistsException<T>`, ... | `RootBlocks.Exceptions` |

## Entities: `Entity<T>`

`Entity<T>` is the base class for anything with an identity.

```csharp
public abstract class Entity< T > : IEntity, IDatable, IEquatable< Entity< T > >
    where T : IEquatable< T >
```

| Member | Description |
|--------|-------------|
| `T Id` | The identity. It has a private setter and is assigned through the `protected Entity( T id )` constructor. |
| `DateTime CreatedOn` | Set to UTC now when the entity is first saved through a `DatabaseContext`. It is `virtual` so lazy-loading proxies can override it. |
| `DateTime LastModifiedOn` | Set to UTC now on creation and on every later save that modifies the entity. |
| `IReadOnlyCollection<DomainEvent> DomainEvents` | Events raised since the last commit. |
| `protected void AddDomainEvent( DomainEvent )` | Records an event. The unit of work collects these events on commit. |
| `void ClearDomainEvents()` | Empties the list. The unit of work calls this after collecting the events. |

Two entities are equal when they have the same `Id`. The comparison uses `Equals`, `==`, `!=` and `GetHashCode`, and ignores every other property. `ToString()` returns `"TypeName [Id=...]"`.

The parameterless `protected Entity()` constructor is there for materialization. EF sets the `Id` itself in that case.

### Identifiers

RootBlocks deliberately ships no identifier type. `T` can be any `IEquatable<T>`, such as `Guid`, `int`, `string`, or a struct of your own. IDs are assigned by the domain when the entity is constructed. They are never generated by the database, and the EF configurations enforce this with `ValueGeneratedNever()`.

For strongly-typed IDs (`PostId`, `BlogId`), use [StronglyTypedIdentifier](https://github.com/sebdesalvador/StronglyTypedIdentifier). Its source generator produces the struct, a `New()` factory and a `TryParse` method for route binding. Its companion packages add EF Core conventions (`UseStronglyTypedIdentifiers()`) and OpenAPI descriptions (`AddStronglyTypedIdentifiers()`).

```csharp
public partial struct PostId : IStronglyTypedIdentifier< Guid >;

public class Post : Entity< PostId >, IAggregateRoot
{
    public Post( string title ) : base( PostId.New() ) => Title = title;
    // ...
}
```

## Aggregate roots: `IAggregateRoot`

`IAggregateRoot` is a marker interface. Put it on the entity at the root of each aggregate, and leave it off the entities inside the aggregate.

```csharp
public class Post : Entity< PostId >, IAggregateRoot { }   // root
public class Comment : Entity< CommentId > { }             // child, reached through Post
```

The marker is used in two places:

- `IRepository<T> where T : IAggregateRoot` means you can only declare repositories for roots.
- `IUnitOfWork.RegisterNew/Clean/Dirty/Deleted` only accept an `IAggregateRoot`. You register the root, and EF follows its navigations to the children.

## Value objects: `ValueObject`

A value object has no identity. Two instances are equal when every one of their atomic values is equal.

```csharp
public class Address : ValueObject
{
    public string Street { get; private init; }
    public string City { get; private init; }

    public Address( string street, string city ) => ( Street, City ) = ( street, city );

    protected override IEnumerable< object > GetAtomicValues()
    {
        yield return Street;
        yield return City;
    }
}

new Address( "1 Main St", "Springfield" ) == new Address( "1 Main St", "Springfield" ); // true
```

- Values are compared pairwise and in order. Return them in a stable order.
- `null` values are supported. Two `null`s are equal, and a `null` never equals a non-null value.
- `GetHashCode()` XORs the hashes of the atomic values.
- `GetClone()` returns a shallow copy made with `MemberwiseClone`.

Make value objects immutable by using `init` or private setters, and validate in the constructor or the setters. To store a value object in its own table, see [`ValueObjectConfiguration<T>`](../packages/entity-framework.md#entity-configurations).

## Enumerations: `Enumeration`

`Enumeration` is a class-based replacement for C# `enum` (see the [Microsoft guidance](https://learn.microsoft.com/en-us/dotnet/architecture/microservices/microservice-ddd-cqrs-patterns/enumeration-classes-over-enum-types)). Each value has a `Guid Id` and a `string Name`, it can carry behaviour, and it can be stored as a seeded lookup table.

```csharp
public class PostStatus : Enumeration
{
    public static readonly PostStatus Draft     = new( Guid.Parse( "00000000-0000-0000-0000-000000000001" ), nameof( Draft ) );
    public static readonly PostStatus Published = new( Guid.Parse( "00000000-0000-0000-0000-000000000002" ), nameof( Published ) );
    public static readonly PostStatus Archived  = new( Guid.Parse( "00000000-0000-0000-0000-000000000003" ), nameof( Archived ) );

    private PostStatus( Guid id, string name ) : base( id, name ) { }
}
```

> **Declare every value as a `public static readonly` field on the subclass itself.** `GetAll<T>()` reflects over the public, static, declared-only fields of `T`. A property, a non-public field, or a field declared on a base class is not found, and neither `FromValue` nor `FromDisplayName` will be able to return it.

| Member | Description |
|--------|-------------|
| `Enumeration.GetAll<T>()` | Every declared value of `T`. |
| `Enumeration.FromValue<T>( Guid )` | Returns the value with that `Id`. Throws `InvalidOperationException` if there is none. |
| `Enumeration.FromDisplayName<T>( string )` | Returns the value with that `Name`, compared case-sensitively. Throws `InvalidOperationException` if there is none. |
| `==`, `!=`, `<`, `<=`, `>`, `>=` | Compare by `Id`. |
| `ToString()` | Returns `"Name [Id=...]"`. |

Use fixed, hard-coded `Guid`s, never `Guid.NewGuid()`. The IDs are seeded into the database and stored in foreign keys, so they must not change from one run to the next.

A common pattern is to store the foreign key and expose the enumeration through a getter:

```csharp
public Guid PostStatusId { get; private set; }
public virtual PostStatus PostStatus => Enumeration.FromValue< PostStatus >( PostStatusId );
```

`DatabaseContext` detaches every tracked `Enumeration` before it saves. This means assigning an enumeration to a navigation never makes EF try to insert or update a row in the lookup table.

### `TranslatableEnumeration`

`TranslatableEnumeration` adds a `string Key`, typically a resource key for localized display text. Use it when `Name` is a technical identifier and users need translated labels.

```csharp
public class Country( Guid id, string key, string name ) : TranslatableEnumeration( id, key, name )
{
    public static readonly Country Belgium = new( Guid.Parse( "..." ), "country.belgium", "BE" );
}
```

## Domain events: `DomainEvent`

`DomainEvent` is the abstract base class for things that happened in the domain. It implements MediatR's `INotification`.

| Property | Description |
|----------|-------------|
| `Guid Id` | A new `Guid` for each event. It is also used as the outbox row key. |
| `Guid? CausationId` | The ID of the message that caused this event, if any. |
| `Guid CorrelationId` | Ties together every message in one business flow. Defaults to `Guid.Empty`. |
| `DateTime OccurredOn` | UTC time at which the event was constructed. |
| `string TypeName` | The event's short type name, such as `"PostPublished"`. |
| `string AssemblyQualifiedTypeName` | Used to find the concrete type again when the event is deserialized. |

```csharp
public class PostPublished( PostId postId ) : DomainEvent
{
    public PostId PostId { get; } = postId;
}

// inside the aggregate
AddDomainEvent( new PostPublished( Id ) );
```

`SetCorrelationIds( causationId, correlationId )` fills in the tracing IDs. You can also pass them through the `protected DomainEvent( Guid? causationId, Guid correlationId )` constructor. When an `IExecutionContext` is registered, the MediatR `EventPublisher` calls `SetCorrelationIds` for you just before publishing (see [Messaging](../packages/messaging-mediatr.md)).

Events are collected and published by the unit of work when you commit. Raising an event does nothing else on its own. See [Entity Framework persistence](../packages/entity-framework.md#unit-of-work) for the exact sequence.

## Repositories and the unit of work

```csharp
public interface IRepository< T > where T : IAggregateRoot;
```

`IRepository<T>` has no members. Each repository interface declares only the queries its aggregate needs, which keeps the domain free of a generic CRUD surface:

```csharp
public interface IPostRepository : IRepository< Post >
{
    Task< Post > GetByIdAsync( PostId postId, CancellationToken cancellationToken = default );
}
```

Repositories only load aggregates. To persist changes, register them with the `IUnitOfWork`:

| Method | Use it when |
|--------|-------------|
| `RegisterNew( root )` | You created the aggregate. |
| `RegisterDirty( root )` | You changed an aggregate that is already tracked, typically one loaded through a repository. |
| `RegisterDeleted( root )` | You want to delete a tracked aggregate. Soft-deletable entities are marked, not removed. |
| `RegisterClean( root )` | You want to attach an aggregate as unchanged, for example one rebuilt outside the context. |
| `Commit()` / `CommitAsync()` | You are ready to save and publish the domain events. |
| `Rollback()` | You want to revert the tracked, uncommitted changes in memory. |
| `BeginTransaction[Async]()`, `CommitTransaction[Async]()`, `RollbackTransaction()` | You need to span several commits with one explicit database transaction. |

The EF Core implementation and its edge cases are described in [Entity Framework persistence](../packages/entity-framework.md#unit-of-work).

## Exceptions

All exceptions are in `RootBlocks.Exceptions`.

### `DomainException`

`DomainException` is the abstract base for business-rule violations. Its message is the `Name` of the `Enumeration` code you pass in, and the code itself is kept in `ExceptionCode`. The API layer can map codes to responses without parsing strings.

```csharp
public class PostExceptionCode : Enumeration
{
    public static readonly PostExceptionCode TitleTooLong = new( Guid.Parse( "..." ), "TITLE_TOO_LONG" );
    private PostExceptionCode( Guid id, string name ) : base( id, name ) { }
}

public class PostException( PostExceptionCode code, Exception? inner = null ) : DomainException( code, inner );

throw new PostException( PostExceptionCode.TitleTooLong ); // Message == "TITLE_TOO_LONG"
```

### `EntityNotFoundException<T>` and `EntityAlreadyExistsException<T>`

Repositories and queries throw these. `T` is the entity type, and its full name appears in the message.

```csharp
throw new EntityNotFoundException< Post >( nameof( Post.Id ), postId );
// "Cannot find 'MyApp.Core.Post' where Id = '6f9...'."

throw new EntityAlreadyExistsException< Person >( nameof( Person.EmailAddress ), email );
// "'MyApp.Core.Person' where EmailAddress = 'a@b.c' already exists."
```

Each has a parameterless constructor with a generic message, and overloads that take a property name and an `int`, `string` or `object` value. Because the exception type is generic, a minimal API endpoint can catch exactly the case it handles:

```csharp
catch ( EntityNotFoundException< Post > ) { return TypedResults.NotFound(); }
```

Both derive from the abstract `EntityException<T>`. You can derive your own entity exceptions from it. Its message template replaces `{{Entity}}`, `{{PropertyName}}` and `{{PropertyValue}}`.

### Other exceptions

| Exception | Thrown when |
|-----------|-------------|
| `AssemblyQualifiedNameNullException` | A `DomainEvent` subtype has no assembly-qualified name. This should not happen with normal types. |
| `CannotCloneNullValueObjectException` | `ValueObject.GetClone()` could not produce a copy. |
| `NotAModuleException` | It is reserved for module discovery. RootBlocks itself does not throw it. |

The persistence-specific exceptions (`ConcurrencyException` and others) are described in [Entity Framework persistence](../packages/entity-framework.md#exceptions).
